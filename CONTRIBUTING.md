# Contributing to HyperION

Thank you for helping make HyperION better. The application source code is not published in this repository, so the most valuable contributions are clear bug reports, well-described feature requests and feedback on releases.

## Report a bug

1. Update to the latest version from the [download page](https://www.hyperiondaw.com/download), Steam or the Microsoft Store.
2. Check whether the problem also happens in a new, empty project.
3. Search [existing issues](https://github.com/HyperionDAW/HyperION/issues) and add your details to a matching one instead of opening a duplicate.
4. Open the [bug report form](https://github.com/HyperionDAW/HyperION/issues/new?template=bug_report.yml) and include:
   - HyperION version, edition and where you installed it
   - Operating system, audio driver (for example Windows Audio, ASIO, Core Audio, ALSA or PipeWire), audio interface, sample rate and buffer size
   - Exact steps that reproduce the problem, what you expected and what happened
   - Logs from `Documents/HYPERION/Logs` (Windows) when relevant, with personal information removed

One problem per issue keeps fixes fast and easy to track.

## Suggest a feature

Use the [feature request form](https://github.com/HyperionDAW/HyperION/issues/new?template=feature_request.yml). Start with the production problem you want to solve, then describe the workflow you would like. Screenshots, sketches or a short screen recording help a lot.

## Translations and documentation

HyperION ships in 31 languages. If a translation is wrong or unclear, open an issue with the language, the text you see, where it appears and your suggested wording.

## What not to post publicly

- Licence keys, receipts, e-mail addresses or account details: use the [contact page](https://www.hyperiondaw.com/contact).
- Security vulnerabilities: follow the [security policy](SECURITY.md).
- Audio, projects or artwork you do not have the right to share.

## Conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
